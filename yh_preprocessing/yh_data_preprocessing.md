# SK매직 FAQ 데이터 전처리

SK매직 FAQ 크롤링 데이터를 RAG(Retrieval-Augmented Generation) 시스템에 최적화된 형태로 전처리하는 도구입니다.

## 주요 기능

### 1. 텍스트 정제
- 해시태그 제거 (#한글, #영문, #숫자)
- 특수기호 제거 (☞, ▶, ▣, •, √, →, ※, ✅, ⭐)
- 고객상담센터 및 연락처 정보 제거
- 서비스 안내 문구 제거
- 연속된 마침표 정규화 (.. → .)
- 큰 따옴표(") 제거
- 공백 정규화 (연속된 공백 → 하나의 공백)

### 2. 표 데이터 최적화
- **table_markdown**: [표N] 앞의 불필요한 빈 줄 제거 (표 구조는 유지)
- **table_text**: Markdown 표를 자연어 텍스트로 변환하여 RAG 검색 성능 향상

### 3. 중복 제거
- 전체 행 중복 제거
- text 컬럼 기준 중복 제거
- 빈 텍스트 제거
